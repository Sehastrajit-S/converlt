## Description [up to 10,000]

Converlt is an IDE for training machine-learning models. It's built on the open-source core of VS Code, so your editor habits, keyboard shortcuts and extensions carry over, and it adds everything between your training code and a GPU.

TRAIN ON ANY GPU
Connect a Linux GPU machine over SSH, or use your own NVIDIA GPU through WSL2. Click Run, and Converlt copies your code to the machine, starts training under a supervisor that keeps going if you disconnect, and streams logs, metrics and GPU use back to the editor.

KNOW WHY A RUN FAILED
Converlt catches NaN losses, out-of-memory errors and stalled runs as they happen, down to the line in your code. When a run turns out worse than an earlier one, it compares the two and ranks the likely causes: a changed setting, code, data, environment or hardware.

FROM DATASET TO MODEL
Profile a dataset and fix the problems Converlt finds, such as leaked labels, ID columns, missing values and class imbalance. Then design a model by dragging layers in the Model Builder, starting from 40 templates, and Converlt writes the training code.

RUN BETTER EXPERIMENTS
Run a sweep over learning rates or other settings, see the GPU memory and time a job needs before you launch it, and get an experiment report that ranks your runs, shows the model's worst mistakes and suggests what to try next.

SHARE AND REPRODUCE
Every run records the exact code, data, environment and settings. Send a run to a teammate as a file, and they can reproduce it with the same code and data. Converlt then checks whether they got the same result.

NEW TO MACHINE LEARNING?
The ML Guide walks you through it one step at a time: data, preparation, model, training, evaluation, improvement and sharing.

OPEN SOURCE
Converlt is open source under the Apache License 2.0: https://github.com/Sehastrajit-S/converlt

You need a GPU to train on: a Linux machine you can reach over SSH, or an NVIDIA GPU in this PC with WSL2.
